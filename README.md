# InvenTrace

A small project exploring multi-echelon inventory optimization using the M5 Walmart sales dataset.

The idea: instead of setting reorder points independently at each level of a supply chain (store, state, national), coordinate them together and see how much cost that saves. It Uses `stockpyl` for the optimization.

## Stack
Python, pandas, NumPy, SciPy, stockpyl, FastAPI

open `inventrace.ipynb` to see it as a notebook.
